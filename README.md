# U.R.C.A. UNIFIED RAZER CONTROL APP.
Personal open source project, if you actually want to use it, you should instead try out FreeRazer or the drivers on OpenRazer.
Reason? Well if you didn't read the post, this is a personal project for my devices. Why do I not take it any further? Well because to add headphones you actually need to have them physically since no one did this yet, so I am limited and I think FreeRazer does it better.
Still, all yours to download and use, for some reason.
